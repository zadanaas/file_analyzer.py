# 🧠 File Analyzer

A Python tool for educational cybersecurity projects.  
It scans directories, collects file metadata, calculates hashes, and flags suspicious patterns.

## 🚀 Features
- File metadata (size, type, last modified)
- MD5 and SHA256 hash calculation
- Suspicious file detection (based on extensions)
- JSON output for easy integration

## 🧩 Usage
```bash
python file_analyzer.py
